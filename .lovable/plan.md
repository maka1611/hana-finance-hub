Понял — это **средства компании** (не личные владельца). Переименовываю раздел и сущности соответственно.

## Раздел «Средства компании» (`/admin/company-funds`)

Доступен только владельцу. Полная отчётность по собственному капиталу компании отдельно от средств инвесторов.

## 1. Учёт операций со средствами компании

Новая таблица `company_funds_operations`:
- тип операции: `deposit` (пополнение), `withdraw` (вывод), `adjustment` (корректировка)
- сумма, дата операции, комментарий, кто провёл

UI: список операций + формы «Пополнить» / «Вывести» / «Корректировка».

Текущий баланс средств компании = Σ депозитов − Σ выводов + прибыль − выплаты инвесторам − расходы.

## 2. Дашборд показателей (карточки сверху)

- **Капитал компании всего** (внесено в компанию)
- **В обороте сейчас** (сумма активных контрактов без `investor_id`)
- **Свободно (простаивает)** — капитал минус оборот
- **Загрузка %** средств компании
- **Прибыль со средств компании** (наценка по контрактам без инвестора)
- **Прибыль с инвесторских средств** (доля компании = `1 − profit_share_rate`)
- **Выплачено инвесторам** (их доля от закрытых платежей)
- **Чистая прибыль компании** = прибыль со своих средств + доля компании с инвесторов − расходы

## 3. Динамика по периодам

График + таблица с выбором периода (день/неделя/месяц/произвольный диапазон) — те же показатели, что в существующей `/admin/analytics`, но в разрезе **источника средств**:
- средства компании vs инвесторские
- доход с оборота собственных средств
- доход с инвесторов (доля компании)
- депозиты/выводы средств компании за период

## 4. Раскладка по инвесторам

Таблица: инвестор → внесено → в обороте → простаивает → заработал инвестор → заработала компания с него → выплачено → к выплате.

## 5. Что ещё предлагаю добавить для полноты

- **Прогноз поступлений** — сумма ожидаемых платежей по графику на 30/60/90 дней (отдельно свои/инвесторские)

## Технические детали

- Миграция: таблица `company_funds_operations` (+ опционально `company_expenses`), RLS только для владельца, GRANT authenticated/service_role.
- `src/lib/company-funds.functions.ts` — server fns: `recordOperation`, `getCompanyFundsSummary`, `getCompanyFundsDynamics(period)`, `getCompanyFundsByInvestor`, `exportCompanyFundsReport`.

- Расчёты переиспользуют существующие функции аналитики, добавляя фильтр `investor_id IS NULL` / `IS NOT NULL`.
