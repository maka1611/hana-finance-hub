## Идея

Полная смена визуального языка на **финтех-дэшборд** уровня Revolut/Mercury: тёмная тема по умолчанию, плотные данные, крупные числовые метрики, монохромная база Midnight Indigo с одним электрическим акцентом. Клиентский кабинет, админка, лендинг и авторизация — единая система, но админка сохранит чуть более плотную сетку.

## Дизайн-токены

Обновление `src/styles.css`:

- **Палитра (dark по умолчанию, есть light):**
  - `--background` `#0a0a1a` (oklch 0.14 0.03 275)
  - `--card` `#141432` (0.19 0.05 275)
  - `--muted` `#1e1e5a` @ 40% (0.26 0.09 275)
  - `--primary` `#4f46e5` (индиго-электрик, 0.55 0.22 275)
  - `--primary-glow` для градиентов и свечения кнопок
  - `--border` тонкий `oklch(1 0 0 / 8%)`
  - `--success` изумруд (для «оплачено»), `--warning` янтарь, `--destructive` красный
- **Радиусы:** `--radius: 0.625rem` (чуть острее чем сейчас)
- **Тени:** `--shadow-elevated` — многослойная тень с индиго-свечением
- **Градиенты:** `--gradient-primary` (индиго → фиолет), `--gradient-surface` (для карточек-метрик)
- Клиент и админка используют **одну палитру**; админка отличается только плотностью сетки и наличием sidebar-акцента, а не цветом (сейчас у неё отдельная серая схема — она уйдёт)

## Типографика

- `Sora` (weights 400/600/700) — заголовки, крупные числа метрик, hero
- `Manrope` (400/500/600) — body, таблицы, формы
- `IBM Plex Mono` оставляем для монолейблов
- Установка через `@fontsource/sora` и `@fontsource/manrope`, импорт в `src/routes/__root.tsx`
- Числа в метриках — `font-variant-numeric: tabular-nums` для ровных колонок

## Компонентные паттерны

- **Metric-карточки:** большая цифра (Sora 700, 40–48px), под ней подпись капсом Plex Mono, слева цветная точка-индикатор, справа тренд-стрелка
- **Таблицы:** тёмный фон, hover-подсветка индиго-строкой, sticky-header, статус-бейджи-пилюли
- **Sidebar:** узкий (72px collapsed / 240px expanded), иконки со свечением активного пункта
- **Кнопки:** primary — градиент индиго с subtle glow-shadow; ghost — тонкая рамка
- **Формы:** плавающие лейблы, focus-ring индиго-glow, ошибки красным инлайн
- **Графики (recharts):** индиго-заливка с прозрачностью, тонкие сетки, tooltip тёмный с рамкой

## Микро-анимации (framer-motion)

- Metric-числа: count-up при монтировании (250мс)
- Sidebar-переходы страниц: слайд+fade (уже есть, оставим)
- Кнопки: subtle scale 0.98 при active
- Hover карточек: border-color transition + lift 2px
- Skeleton-состояния для загрузки таблиц/метрик

## План работ

1. Установить `@fontsource/sora` и `@fontsource/manrope`, подключить в `__root.tsx`, обновить `body` font-family
2. Переписать `src/styles.css`: новые токены :root/.dark, убрать `.admin-theme`, добавить утилиты градиентов/glow, обновить `girih-pattern` тинты
3. `use-theme.tsx` → дефолт dark
4. Обновить Button variants и добавить `MetricCard` компонент в `src/components/ui/`
5. Редизайн landing (`routes/index.tsx`) и auth-страниц
6. Редизайн клиентского кабинета: `app.index` (dashboard с метриками), таблицы рассрочек, calculator
7. Редизайн админки: `admin.index`, `admin.analytics`, `admin.company-funds`, таблицы клиентов/контрактов/платежей/инвесторов
8. Обновить sidebar-компоненты
9. Проверить контраст и читаемость (кириллица Ш/Щ/М в Sora), пройтись по формам и модалкам
