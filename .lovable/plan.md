## Что меняем в `src/lib/reports.functions.ts`

### 1. Чистка данных
- **Пустые строки в «График платежей»**: фильтровать записи, у которых контракт удалён (`deleted_at != null`) или не найден среди активных контрактов. Сейчас расписания тянутся отдельно от контрактов, без фильтра по `deleted_at`, поэтому появляются строки только с датой и суммой.
- **Статус `rescheduled`**: добавить перевод в `RU_STATUS_PAYMENT` → «Перенесён». Заодно добавить `scheduled` если встретится.
- **Без копеек**: все денежные значения округлять до целого рубля (`Math.round`) и форматировать как `#,##0 "₽"` вместо `#,##0.00 "₽"`. Применяется ко всем листам.

### 2. Лист «Инвесторы» — переработка
Заменить текущий формат на иерархический отчёт по каждому инвестору. Старый отдельный лист «Вложения инвесторов» убирается.

Для каждого инвестора одна шапка-строка + строки по его контрактам:

```text
ИНВЕСТОР: <ФИО>   Капитал: 500 000 ₽   Доля: 30%   Контактов: email/тел
  Контракты, профинансированные его средствами:
  ┌──────────────┬─────────────┬───────────┬──────────┬──────────┬───────────┐
  │ Клиент       │ Товар       │ Сумма     │ Оплачено │ Остаток  │ Прибыль*  │
  ├──────────────┼─────────────┼───────────┼──────────┼──────────┼───────────┤
  │ Иванов И.    │ iPhone 15   │ 120 000   │  40 000  │  80 000  │  9 000    │
  │ Петров П.    │ Ноутбук     │  90 000   │  30 000  │  60 000  │  6 750    │
  ├──────────────┴─────────────┼───────────┼──────────┼──────────┼───────────┤
  │ ИТОГО по инвестору         │ 210 000   │  70 000  │ 140 000  │ 15 750    │
  └────────────────────────────┴───────────┴──────────┴──────────┴───────────┘
```

Поля под каждым инвестором:
- **Капитал** (`total_capital`)
- **Доля прибыли** (`profit_share_rate`)
- **Вложено всего** = сумма `investor_contributions.amount`
- **Сумма контрактов** = Σ `total_sale_price` его контрактов
- **Оплачено по контрактам** = Σ `paid_amount` из `payment_schedules`
- **Остаток к получению** = Σ (amount − paid_amount) по графику
- **Прибыль после сбора всех платежей*** = Σ `markup_amount` × `profit_share_rate` инвестора

\* Прибыль = вся наценка по контрактам инвестора, умноженная на его долю.

Лист реализуется через `aoa_to_sheet` (т.к. структура смешанная: разделители + подытоги). Жирный/серый фон для шапок инвестора.

### 3. Лист «Заявки» — удалить
Убираем чекбокс «Заявки» из UI (`src/routes/_authenticated/admin.analytics.tsx`) и весь блок выборки/генерации `applications` из `reports.functions.ts`.
