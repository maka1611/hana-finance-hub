## Что строим

Блок «Экспорт в Excel» на странице админ-аналитики (`/admin/analytics`). Кнопка скачивания формирует `.xlsx` файл со всеми листами и фильтром по периоду.

## UI (admin.analytics.tsx)

Новая карточка «Отчёты» сверху страницы:
- Пресеты периода: `Сегодня`, `7 дней`, `30 дней`, `Текущий месяц`, `Текущий год`, `За всё время`, `Произвольный` (два DatePicker'а от/до).
- Чекбоксы листов (все включены по умолчанию): Клиенты, Рассрочки, График платежей, Инвесторы, Заявки, Финансовая сводка.
- Кнопка «Скачать Excel» — формирует файл `noorpay-report-YYYY-MM-DD.xlsx`.

Доступ ограничим: блок виден только при `has_role(admin)` или `has_role(owner)` (через `getMyRoles`).

## Серверная функция

Новый файл `src/lib/reports.functions.ts` — `exportReportXlsx`:
- middleware `requireSupabaseAuth` + проверка `has_role(admin|owner)`, иначе 403.
- input: `{ from: string | null, to: string | null, sheets: string[] }`.
- Внутри handler: `await import('@/integrations/supabase/client.server')` для `supabaseAdmin` (нужен полный доступ к данным всех клиентов в обход RLS).
- Параллельно тянем нужные таблицы с фильтрами по «естественным» датам:
  - Клиенты — `profiles.created_at` в диапазоне
  - Рассрочки — `installment_contracts.start_date`
  - График платежей — `payment_schedules.due_date` + join contract/client
  - Инвесторы — `investors.created_at`, плюс `investor_contributions`
  - Заявки — `installment_applications.created_at`
  - Финансовая сводка — агрегаты по контрактам/платежам в периоде
- Формируем `.xlsx` через `xlsx` (SheetJS) — pure JS, работает в Cloudflare Worker.
- Возвращаем `{ base64: string, filename: string }`. Клиент декодит и триггерит download через Blob.

## Содержимое листов

**Клиенты**: ID, ФИО, Email, Телефон, Дата регистрации, Кол-во активных рассрочек, Общая сумма контрактов, Остаток к выплате.

**Рассрочки**: ID, Клиент (ФИО+email), Товар, Дата старта, Срок (мес), Цена товара, Наценка, Итого, Ежемесячный платёж, Оплачено платежей / всего, Сумма оплачено, Остаток, Статус.

**График платежей**: ID контракта, Клиент, Товар, № платежа, Дата платежа, Сумма, Статус (оплачен/ожидает/просрочен), Дата оплаты.

**Инвесторы**: ФИО, Email, Телефон, Дата регистрации, Кол-во вложений, Сумма вложений, Статус. Доп. лист «Вложения инвесторов» — детальный список contributions.

**Заявки**: Дата, Клиент, Товар, Сумма, Срок, Статус, Менеджер.

**Финансовая сводка**: ключевые метрики за период — выдано контрактов (шт/сумма), получено платежей, ожидается, просрочено, общая наценка (выручка), активных рассрочек на конец периода, новых клиентов, новых инвесторов, привлечено инвестиций.

## Зависимости

Добавить `xlsx` (`bun add xlsx`) — работает в Worker-рантайме, без нативных модулей.

## Технические детали

- Дата фильтра передаётся как ISO строки; `null` = без границы (значит «за всё время» при обоих null).
- Форматирование чисел через числовой формат ячеек (`#,##0.00 ₽`), заголовки жирные, ширина колонок авто (по макс длине значений).
- На листах ставим автофильтр и freeze первой строки.
- Имя файла: `noorpay-report-{from|all}-{to|now}.xlsx`.
